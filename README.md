# Renscraft 🚀 - AI Website Builder

Renscraft adalah *AI-powered website builder* yang menulis kode React asli. Tulis deskripsi website impianmu, lihat AI membangunnya secara *real-time*, revisi desainnya lewat chat, lalu publish atau export kodenya!

## ✨ Fitur Utama

- **AI Code Generation**: Menghasilkan kode React (JSX) yang bersih dan siap produksi.
- **Live Preview**: Preview langsung di browser (menggunakan Sandpack) selagi AI menulis kode.
- **Chat-Based Revisions**: Minta AI mengubah bagian website tertentu cukup dengan instruksi teks.
- **Manual Payment Flow**: Pembayaran via transfer bank manual (Midtrans otomatis *coming soon*).
- **Publish & Export**: Bagikan link website secara publik atau download *source code* dalam bentuk ZIP.
- **Secure Hosting**: Backend berjalan di laptop/server lokal yang diekspos dengan aman via **Cloudflare Tunnel** (anti-DDoS & bebas CGNAT).

## 🛠️ Tech Stack

**Frontend:**
- [React 19](https://react.dev/)
- [Vite](https://vitejs.dev/)
- [Tailwind CSS v4](https://tailwindcss.com/)
- [Sandpack React](https://sandpack.codesandbox.io/)
- [React Router v7](https://reactrouter.com/)

**Backend:**
- [Node.js](https://nodejs.org/) (Express)
- [MongoDB](https://www.mongodb.com/) (Mongoose)
- [Cloudflare Tunnel](https://www.cloudflare.com/products/tunnel/)
- [Midtrans](https://midtrans.com/) (Payment Gateway - *Coming Soon*)
